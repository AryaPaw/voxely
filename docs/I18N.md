# Interface languages

## Goal

Ship Russian and English UI. Default is Auto: follow Windows / browser language. The user can pin RU or EN in Appearance.

Speech-to-text `language` stays a separate setting. Do not reuse it for the chrome.

## Phases

1. Catalog: keep `src/lib/i18n.ts` as the only UI string table. Overlay, errors, tray, installer, and `AppError::user_message` still have hard-coded Russian and move here next.
2. Overlay and tray menus must read the same resolved locale as the main window.
3. Dates/numbers: `Intl` with the resolved locale (`ru-RU` / `en-US`).
4. Rust user-facing errors: pass locale into `user_message` or return a code the UI maps.
5. Do not translate DSP preset technical names until copy is reviewed.

## Rules

- No third-party i18n runtime unless string count makes `i18n.ts` painful.
- Auto never overrides an explicit RU/EN choice.
- New UI copy lands in both dictionaries in the same change.
