# OBS filter mapping

Primary import path: local Scene Collection JSON under `%APPDATA%\obs-studio\basic\scenes\`.

WebSocket is optional and was not configured on this machine (`[OBSWebSocket]` empty).

Units follow OBS filter JSON: dB, ms, ratio.

Unsupported filters are listed in the import preview and never silently replaced (no VST, NVIDIA, EQ emulation).
